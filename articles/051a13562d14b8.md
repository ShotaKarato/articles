## Canvas要素とは？
詳細についてはMDNのドキュメントが参考になるかと思いますが、めちゃくちゃざっくりまとめるとCanvas要素は以下のようなイメージの要素になります。

https://developer.mozilla.org/ja/docs/Web/HTML/Reference/Elements/canvas

- グラフィックやアニメーションの描画ができる要素
- [キャンバスAPI](https://developer.mozilla.org/ja/docs/Web/API/Canvas_API)を利用して、JS経由でグラフィックの描画を行うことが可能

なんに使っていいかよくわかんないけど、なんかめっちゃ便利そう。

## 🔨 早速作ってみた 🔨
![Canvas要素を使った実装例](./images/canvas02.gif =400x)
ということで早速作ってみました！
めちゃくちゃ雑な実装例ですが画像が切り替わると同時にテキストカラーも動的に変わっているのがわかるかと思います。
以下が実際のコードで、ここからはCanvas要素を使ってどのように背景色に応じて動的にテキストカラーを変更しているのかを解説していきます。
（サンプル画像のローテーション部分など今回のトピックにあまり関係のない部分は説明を割愛させていただきます🙇🏻‍♂️）

```typescript 
const images = [
  "/src/images/bright01.jpg",
  "/src/images/dark01.jpg",
  "/src/images/middle01.jpg",
] as const;

const image = document.getElementById("image") as HTMLImageElement;
const text = document.getElementById("text") as HTMLParagraphElement;
const imageRotateButton = document.getElementById(
  "image-rotate-button"
) as HTMLButtonElement;

let currentIndex = 0;

// ---- Canvas関連の定数 ----
const CANVAS_WIDTH = 400;
const CANVAS_HEIGHT = 300;
const SAMPLE_WIDTH = 150;
const SAMPLE_HEIGHT = 34;
const SAMPLE_X = (CANVAS_WIDTH - SAMPLE_WIDTH) / 2;
const SAMPLE_Y = CANVAS_HEIGHT - SAMPLE_HEIGHT;

// ---- 背景画像の色味に合わせてテキストカラーを変更する処理 ----
const updateTextColorFromImage = (img: HTMLImageElement) => {
  const canvas = document.createElement("canvas");
  canvas.width = CANVAS_WIDTH;
  canvas.height = CANVAS_HEIGHT;

  const ctx = canvas.getContext("2d");
  if (!ctx) return;

  ctx.drawImage(img, 0, 0, CANVAS_WIDTH, CANVAS_HEIGHT);

  const imageData = ctx.getImageData(
    SAMPLE_X,
    SAMPLE_Y,
    SAMPLE_WIDTH,
    SAMPLE_HEIGHT
  );

  const { r, g, b } = getAverageColor(imageData);
  const brightness = getBrightness(r, g, b);

  text.style.color = brightness > 128 ? "black" : "white";
};

const getAverageColor = (imageData: ImageData) => {
  const data = imageData.data;
  const pixelCount = data.length / 4;

  let r = 0;
  let g = 0;
  let b = 0;

  for (let i = 0; i < data.length; i += 4) {
    r += data[i];
    g += data[i + 1];
    b += data[i + 2];
  }

  return {
    r: Math.floor(r / pixelCount),
    g: Math.floor(g / pixelCount),
    b: Math.floor(b / pixelCount),
  };
};

const getBrightness = (r: number, g: number, b: number) =>
  0.299 * r + 0.587 * g + 0.114 * b;

// ---- 背景画像をローテーションさせる処理 ----
const rotateImage = () => {
  currentIndex = (currentIndex + 1) % images.length;
  image.src = images[currentIndex];
};
image.addEventListener("load", () => {
  updateTextColorFromImage(image);
});
imageRotateButton.addEventListener("click", rotateImage);

// 初期表示
image.src = images[currentIndex];
```

### Canvas要素の作成
`updateTextColorFromImage`関数内ではまず最初にCanvas要素を作成しています。
💡このCanvas要素ですが一体何に使用するかというと、実は画面上に表示されるわけではなく色味の判定をしたい背景画像を描画させて色味の情報を取得するのに使用します。

```typescript
const canvas = document.createElement("canvas");
canvas.width = CANVAS_WIDTH;
canvas.height = CANVAS_HEIGHT;

const ctx = canvas.getContext("2d");
if (!ctx) return;

ctx.drawImage(img, 0, 0, CANVAS_WIDTH, CANVAS_HEIGHT);
```

- `getContext`に`2d`を渡して呼び出すことで、図形・文字・画像の描画に使用できる2次元描画コンテキストを取得
- 取得した2次元描画コンテキストに`drawImage`で対象の背景画像を描画

### 描画した画像データから色味の情報を取得
Canvas要素に背景画像を描画したら、次にその描画データから色味の情報を取得していきます。
以下のコードでは、`getImageData`メソッドを使用してCanvas要素に描画された画像データの一部を取得しています。

```typescript
const imageData = ctx.getImageData(
  SAMPLE_X,
  SAMPLE_Y,
  SAMPLE_WIDTH, // 150
  SAMPLE_HEIGHT // 34
);
```
- パラメータにx座標、y座標などの指定を加えることで特定の範囲のデータを取得可能です
- 今回の場合は、テキストが配置される部分の色味が取得できれば良いので以下の画像にある領域を対象にデータを取得できるようパラメータの設定を行なっています

![Canvas要素のサンプリング領域](./images/canvas03.png =400x)

`getImageData`で取得したデータには、選択した範囲の画像データ情報（RGBA値）が1pixelごとに配列形式で格納されています。

![getImageDataが返却するデータ](./images/canvas04.png =400x)

### 色味・明るさの判定
まずは前段のステップで取得した選択範囲の画像データから平均的なRGB値を算出します。
処理は至ってシンプルで、RGBA値が格納された配列をループで回してR・G・Bの値をそれぞれ合計し、最後にピクセル数で割ることで平均値を求めています。

```typescript
const getAverageColor = (imageData: ImageData) => {
  const data = imageData.data;
  const pixelCount = data.length / 4;

  let r = 0;
  let g = 0;
  let b = 0;

  for (let i = 0; i < data.length; i += 4) {
    r += data[i];
    g += data[i + 1];
    b += data[i + 2];
  }

  return {
    r: Math.floor(r / pixelCount),
    g: Math.floor(g / pixelCount),
    b: Math.floor(b / pixelCount),
  };
};
```

そして算出した平均値を明るさを算出するための公式に当てはめて、対象となる画像の明るさを求めます。

自分はここで初めて明るさを求めるための公式があることを知りました笑
明るさを求めるための公式：https://www.w3.org/TR/AERT/#color-contrast
> Color brightness is determined by the following formula:
((Red value X 299) + (Green value X 587) + (Blue value X 114)) / 1000

```typescript
const getBrightness = (r: number, g: number, b: number) =>
  0.299 * r + 0.587 * g + 0.114 * b;
```

```typescript
const { r, g, b } = getAverageColor(imageData);
const brightness = getBrightness(r, g, b);

text.style.color = brightness > 128 ? "black" : "white";
```

（今回はサンプル実装のため0-255の中間を境界としてますが、厳密に見やすさを追うのであればWCAGの指標などを参考した方が良さそうです🤔）

## 🚨 注意点 🚨
- Canvasでは同一ドメイン以外の画像データなどを参照するとCross Originエラーの対象となり、`getImageData`がエラーを返すようになってしまう
  - Tainted Canvas（汚染されたCanvas）と呼ぶらしい
- そのため上記の問題を回避するにはcrossorigin attributeに`anonymous`の設定をする対応が必要になります

https://developer.mozilla.org/ja/docs/Web/HTML/How_to/CORS_enabled_image
